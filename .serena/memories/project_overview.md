Automa is a browser extension for Chrome and Firefox that automates browser tasks with a visual block-based workflow builder. Main stack: Vue 3, Webpack 5, Manifest V3, Pinia for state, Dexie for IndexedDB, Tailwind CSS, CodeMirror 6, TipTap. Core workflow runtime lives in src/workflowEngine with WorkflowManager, WorkflowEngine, WorkflowWorker, and blocksHandler modules. Multiple extension contexts exist: background, content script, newtab dashboard, popup, sandbox, offscreen, params, and execute.
