Automa Worker Bootstrap

Use this page to generate the init-tab URL for the worker-driven, no-login WebSocket flow.

Open Dashboard

How to use

  • Start the test backend: node backend-test/server.js.
  • Open the generated /automa-init URL in the same browser profile where the extension is installed.
  • Open the dashboard and wait for the extension to appear in the connected list.
  • Execute a workflow from the dashboard. Full flow will include WS command, action/workflow logs, artifacts, and finish-job callback.
